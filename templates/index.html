Cara Mengambil Cookie Session ID

1
Buka Instagram Web

Buka instagram.com di browser dan pastikan Anda sudah login ke akun Anda.

2
Buka Developer Tools

Tekan tombol F12 (atau klik kanan di sembarang tempat → pilih Inspect / Periksa).

3
Buka Tab Application / Storage

Klik tab Application (di Firefox: Storage) pada panel atas DevTools.

4
Salin Value Cookie sessionid

Di sidebar kiri, klik Cookies → pilih https://www.instagram.com. Cari baris dengan nama sessionid dan salin isinya.

Format: 30869018875%3Axxxxxxxxxx%3A...
Tersalin ke clipboard!
